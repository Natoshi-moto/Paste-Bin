# Programme charter (operator-owned)

## In scope

1. Full **internal** NEX economy (work/compute accounting).
2. Full **internal** LEX economy (social/governance).
3. Participant-facing **internal** wallets/accounts (not crypto wallets).
4. Hard membranes: no NEX↔LEX conversion, no fiat/crypto/external pricing.
5. Local Phase 0A vertical slice (notes, provenance, selected-note export, fake Relay) as a sealed first app gate.
6. Evidence, gates, mutations, independent re-review discipline.

## Out of scope unless new explicit operator decision

- On-chain / blockchain placement
- External markets, bridges, redeemability
- Production deploy / DNS / Cloudflare changes without a one-shot ticket
- Credential creation or provider live calls without a one-shot ticket
- Lifting public `SBX-SOH-001` hold without a dated public decision + site text update

## Lane separation

| Lane | Status |
|------|--------|
| Phase 0A local app gate | Spec repaired in relay v9; awaiting independent re-review |
| Wider Rounds 3–10 / full internal economy | Corpus present; build lane not yet opened as primary programme |
| Public static site | Research hold language still published |

When economy build becomes primary, open an explicit ticket series. Do not silently expand Phase 0A into the full ledger.
